# 質問・TeX・ログをまとめて確認する専用セクション

更新日：2026-10-12。配布版の `#/workspace` は質問・TeXソース・ログから、登録済みの例と簡易チェックを表示します。ヘッダーの「まとめて調べる」から開けます。開発版の学内LLM画面は [LLM_CONNECTION.md](./LLM_CONNECTION.md) を参照してください。

## 入力と結果

質問・ソース・ログのいずれかだけでも利用できます。「確認する」で結果見出しへフォーカスを移します。TeXの編集・ログ・文字コード設定は必要時に開き、入力後だけ「クリア」を表示します。入力を変えると変更前の結果と明示し、行ジャンプを無効にします。

| 入力 | 上限・対応 | 結果 |
| --- | --- | --- |
| したいこと・知りたいこと | 500文字 | 収録済みの用語・別名・症状に関連する説明と固定コード例 |
| ソースの貼り付け／`.tex`選択 | 10,000文字、ファイル64KiB | 基本5規則＋数式内の段落区切り、周辺コード、指摘・開始位置への移動、修正例コピー |
| ログの貼り付け／`.log`選択 | 100,000文字、ファイル256KiB | よくある形式のエラー・警告、報告行、ログの文脈、代表的な報告の確認手順 |

ファイルはUTF-8を既定にし、Shift_JISは利用者が選びます。文字コードを自動推定しません。拡張子・宣言容量・実読み込み容量・文字数・テキストの制御文字を確認し、上限超過や不正な文字コードでは切り捨てずに拒否します。失敗時は既存入力を保持します。遅い読み込みがクリア・編集・画面離脱後に入力を復活させないよう、読み込み要求の世代を確認します。

## 回答の範囲と参照データ

LLMの意味理解や自由な回答生成は行いません。質問内の収録用語、ソースのコマンド、簡易チェックと代表的なログに対応するトピックを照合し、上位3件を提示し、先頭の例を表示、残りの関連例は展開します。結果の件数と「書き方・例へ／ソースの指摘へ／ログの報告へ」の移動ボタンを用意します。用語が見つからなければ、その旨を表示します。

「分数を大きくしたい」など、明示した少数の表現は固定レシピの `dfrac/tfrac` 選択値へ変換します。それ以外のレシピは既定の選択値です。曖昧な質問から任意のテンプレートやコードを作りません。

コード・必要パッケージ・出典は既存の公開トピックと固定レシピから取得します。各例の出典には種類・確認日・参照範囲を表示し、教員の校閲と実TeXコンパイルは未実施と明記します。共通資料は37件です。環境・追加ログ案内の6資料と合わせて43件を登録しています。今回の診断強化に使った6件を再照合し、確認日と必要な参照範囲を更新しました。入力ファイルやログを参照教材・検索索引へ追加する処理はありません。

コード例は個別コピーできます。数式表示は登録済みレシピから生成した例だけを対象にし、開いたときにKaTeXを読み込みます。ユーザーのソース全体、質問中のコード、ログをKaTeXへ渡しません。コピーはLaTeXソースで、数式画像のコピー・PDF生成は対象外です。

## 簡易チェック・タイポ・ログの区別

基本5規則に数式内の空行・parの確認を加えました。対応する開始と終了を比較し、修正例は必要時に展開してコピーできます。詳細は [診断の仕様](./DIAGNOSIS.md) を参照してください。独自マクロ・外部ファイル・動的な構文がある場合は診断を省略する部分があります。指摘ゼロを文書全体の正しさの証明として扱いません。

タイポは `frca → frac`、`alhpa → alpha`、`squrt → sqrt`、`begni → begin`、`itme → item`、`sectoin → section`、`textbold → textbf` の少数の候補だけを扱います。未知のコマンドすべてを誤りにしません。コメント・verb・主なリテラル環境・参照キーを読み飛ばし、読み取れた独自定義は候補から除外します。動的なコマンド構文では照合を省略します。パッケージ等が同じ名前を定義する可能性もあるため、候補と明示して自動置換は行いません。先頭50件が上限です。

ログは主に `! ...`、`file.tex:行: ...`、`LaTeX/Package/Class Warning:` と、近くの `l.行` や `on input line` を読み取ります。報告は先頭100件、各文脈は最大8行・1,200文字です。全ログ形式や複数ファイルの入れ子を解析するものではありません。

報告行と原因の行が異なる場合があります。[Learn LaTeXのエラー解説](https://www.learnlatex.org/ja/lesson-15)でもこの違いを説明しています。このアプリはコンパイラを実行しません。ソースへのログ位置のジャンプは、読み込んだソースとログ内のファイル名が一致し、報告行が範囲内にある場合だけ表示します。ファイル名のない報告や別ファイルへの報告から位置を推測しません。同名でも版が異なる可能性は画面で説明します。

## 情報と安全性

質問・ファイル名・ソース・ログ・結果は画面のReactメモリ内だけで扱います。URL・history state・localStorage・sessionStorage・外部API・学内LLM・解析ログへ送りません。画面離脱・再読み込み・明示クリアで破棄します。通常検索の検索語もメモリ内だけで扱います。文書離脱時はReactルートを解除し、BFCache復帰は空の状態で起動します。

入力中のHTMLを文字列として表示し、スクリプト・TeX・シェルを実行しません。`input/include`・画像・文献の参照先を自動取得しません。関連リンクは登録済みIDから作り、原文や質問をリンクの引数に含めません。入力の利用範囲を拡張する学内LLM契約は追加していません。

専用画面のJS・CSS・解析コードは画面を開いたときに遅延読み込みし、数式用資産はさらに数式表示を開くまで取得しません。通常検索の初期資産の上限と本番CSPを維持します。

## 今後の学内LLM

現行の候補IDだけを送る検索契約では、質問・ファイルに即した自由な回答は提供できません。大学のAPI・利用許可・認証・情報の保存用途が確定した後、質問や選択したソース断片を扱う契約を別に設計します。現在の未設定状態、原文非送信の実装を維持しています。

本セクションはソフトウェアの動作試作です。学生の実利用、教員の校閲、学習効果、完全なTeXコンパイルは未検証です。

目的・症状の言い換え70表現は「探す」と共通です。ログ案内は既存の7分類に、TeX実行先・表の列数・本文の改行・Overfull警告・停止前のエラー確認の5分類を追加しました。表と本文の段落にはコピーできる固定例を示します。Overfullは警告として表示し、PDF作成の失敗と混同しません。TeXコマンドの起動失敗は既知のコマンド名と代表的なOS形式に限定して読みます。任意のコマンドや一般文の「not found」から報告を作りません。
