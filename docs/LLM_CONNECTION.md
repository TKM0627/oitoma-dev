# 開発中の学内LLM接続

通常の `npm run dev` の「まとめて調べる」で、質問とTeX・ログを渡せます。配布用の `npm run build` ではLLMのUI・API処理を除外します。OpenCode、追加ライブラリ、トンネルは不要です。

## 使い方

1. `.env.example` を `.env.local` へコピーし、`OITOMA_API_KEY` と正式な `OITOMA_MODEL` を設定します。既存ファイルは上書きしません。キーはチャット・公開コード・録画へ載せないでください。例のモデルIDは調査報告の候補です。
2. `npm run dev` を実行し、`http://127.0.0.1:5174/oitoma-dev/#/workspace` を開きます。設定変更後は開発サーバーを再起動します。
3. 入口で学内APIを自動確認します。質問は送らず、利用できない場合は入力画面を出しません。
4. 質問を入力し、必要なら `.tex`・`.log` を添付／ドロップ／貼り付けて「送信」を押します。確認画面・同意チェック・手動接続確認はありません。添付を外すと送信対象から外れます。
5. 回答とLaTeXコードをコピーできます。回答待ちの「中止」や「クリア」も使えます。

貼り付けは「TeX・ログを貼り付ける」から開き、文字コードはその中の「添付の設定・上限」で選びます。関連する資料・レシピは回答の「関連資料・試せる例」から開けます。

## アクセス制限の範囲

サーバーが固定HTTPSのモデル一覧を確認し、認証・指定モデル・APIの利用可否を検証します。確認は5秒以内、成功は20秒・失敗は5秒だけキャッシュし、同時の確認はまとめます。送信直前はキャッシュに依存せず再確認し、失敗した場合は質問・ソース・ログを生成APIへ送りません。タブ復帰時も確認し、利用できなくなったら入力・結果を破棄して入力画面を閉じます。

**これはAPIへのアクセス可否による制限であり、学内Wi-Fiの所属証明ではありません。** 大学の許可IP範囲・アクセス制限仕様は未確認です。APIがVPNや学外からも利用可能なら、その環境も通ります。SSIDの推測や架空のIP範囲を使って厳密なWi-Fi限定を装うことはしません。HashRouterのページは同じHTMLから表示するため、入口のUI制限に加え、サーバー側でAPI操作を拒否します。配布版の基本機能は学外でも使えます。

## 情報の扱い

「送信」で質問2,000文字、添付・貼り付けたTeX10,000文字、ログ4,000文字までを送ります。ファイル名・ファイル自体・別画面の入力・検索語は送りません。大きい内容は切り捨てずに拒否します。添付は `.tex`・`.log` 各1件、UTF-8／Shift_JIS対応です。ログ中の氏名・端末のパスは送る前に取り除いてください。

利用環境、関連する公開解説の短い例・出典ID、簡易チェックの先頭6件ずつ、サイト内の57項目の案内も添えます。関連トピックの選択には質問の先頭500文字を使いますが、利用者が入力した質問全体を生成APIへ渡します。外部ページ・学内限定文書・任意ファイルを取得する機能はありません。

キーはサーバー側の認証ヘッダーだけに使い、プロンプトへ含めません。入力にキーと一致する文字列があれば送信を拒否し、回答にあれば表示を拒否します。`.env.local` はGit・開発サーバー配信・公開成果物から除外します。`VITE_` 変数にキーを置かないでください。

入力・回答はアプリのメモリのみで、URL・履歴・Storage・ローカルサーバーのログやファイルへ保存しません。大学API側の保存・学習利用・アクセスログは大学の規則に従います。

## 回答・安全対策

通常の日本語の回答を受け取り、LaTeXのコードブロックをコピー用に抽出します。JSONやJSONコードブロックの回答も検証して扱えます。空の `tool_calls: []` は許容し、実際のツール呼び出し・途中終了・空回答・文字数超過・不可視制御文字を拒否します。推論専用の応答欄は表示しません。

関連リンクは登録済みの種類・IDだけです。通常の文章回答に付くリンクは、入力のローカル検索による候補で、LLMが引用した出典とは扱いません。構造化回答の出典IDは今回提供した登録資料だけを許可します。HTML・外部URLを解釈せず、TeX・シェル・ツールを実行しません。回答内容・コンパイルの正しさは保証しません。

同じOrigin・固定Host・独自ヘッダー・loopbackの接続元を確認し、別サイト・転送ヘッダー・CORSを拒否します。TLS検証の無効化、外部向けHost・proxy、秘密ファイルの配信を拒否します。CSPでiframeとブラウザからの外部API通信を制限します。悪意あるローカルプロセスや端末の侵害を防ぐ境界ではありません。

同時生成1件、操作間隔10秒、起動中30回まで。本文64KiB・5秒、上流応答96KiB・60秒まで。生のエラー本文・例外・ヘッダーはブラウザへ返しません。中止・画面離脱は通信を打ち切りますが、大学側の処理・記録が取り消される保証はありません。自動生成・自動再試行はありません。
