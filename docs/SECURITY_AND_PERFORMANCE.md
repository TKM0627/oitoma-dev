確認日：2026-10-12。静的SPAとしての入力・通信・コード実行・依存・ビルドを対象に対策しています。学内APIやGitHub Pagesの実配信は未接続・未検証です。

## 入力とデータの境界

- 貼り付け・編集したコードはReactのメモリで処理し、HTMLとして挿入しません。URL・履歴・Storage・外部APIへ保存・送信しません。
- 数式に渡すのは、検証済みの列挙値から固定関数で生成した式です。KaTeXは `trust:false`、`maxExpand:200`、`maxSize:10`、`strict:'error'` を使います。
- 検索語100文字、質問500文字、診断コード10,000文字、ログ100,000文字に制限し、診断・ログの表示は先頭100件に限定します。ファイルと貼り付けに共通の制御文字・双方向表示制御の拒否を適用し、黙って文字を削除しません。検索語もメモリ内だけで保持し、URL・history state・Storageへ渡しません。URLへ残す分類は固定の許可リストで再構築し、未知の項目を引き継ぎません。
- 同梱JSONは `validateContent.ts` でスキーマ・出典・参照・生成器を検証します。Viteのビルド開始時と開発サーバーの起動時に必ず実行し、失敗すれば成果物を生成しません。テストも同じ検証器を使います。
- テーマ別資料のJSONは `validateReferenceChapters.ts` で、項目の出典・関連機能・未知のフィールド・検証状況も確認します。本文はReactの文字列として表示し、HTMLやMarkdownの実行処理は加えていません。
- この検証を基本ページの起動時に繰り返さず、Zodは外部応答や引き継ぎ値などの実行時検証が必要な画面だけで読み込みます。`contentRepository.ts` は同梱JSON専用で、外部から受け取るデータを扱う場所ではありません。開発中のJSON変更も本番ビルド時に検証されます。

記号一覧は `validateSymbolCatalog.ts` で出典・ID・コード・未知の項目を検証します。一覧内の100文字以内の絞り込みはメモリ内だけで扱い、URL・Storage・APIへ渡しません。標準の折りたたみを使用し、スクリプトやHTMLを入力から生成しません。

質問・TeX・ログの専用セクションも、全入力と結果をメモリ内だけで扱います。ファイルの拡張子・容量・文字コード・文字数・制御文字を確認し、拒否時は元の入力を保持します。タイポは候補として示し、ソースを書き換えません。ログのパスも外部へ送りません。詳細は [専用セクションの仕様](./WORKSPACE.md) に記録しています。

## 本番HTMLの制限

Viteが本番HTMLの先頭にContent Security Policyを出力します。開発サーバーではHMR用通信・スタイル挿入を使うため、本番の制限は適用しません。検証には `npm run build` 後の `npm run test:e2e` を使います。

```text
default-src 'none'; script-src 'self'; script-src-attr 'none';
style-src 'self'; style-src-attr 'none'; font-src 'self'; img-src 'self';
connect-src 'none'; object-src 'none'; frame-src 'none'; worker-src 'none';
base-uri 'none'; form-action 'none'
```

外部スクリプト、インラインスクリプト、イベント属性、eval、外部フォント・画像、フォーム送信を許可しません。初期設定の `connect-src 'none'` はfetch等の通信を拒否します。明示的な将来Gateway設定があるビルドのみ、そのHTTPS Gatewayの `/v1/` パスを許可します。配信元の静的JS・CSS・フォントは利用できます。参考リンクを選択する通常のページ移動は通信遮断の対象ではありません。

Zodは共通モジュールから `jitless:true` を設定して読み込み、動的な関数生成を使いません。[ZodのCSP対応説明](https://zod.dev/compile)を参照しています。KaTeXのDOM描画が使うCSSOMのプロパティ設定は、インラインstyle属性の禁止とは別に扱われます。[MDNのstyle-src-attr](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/style-src-attr)でこの区別を確認しています。

Viteの `assetsInlineLimit:0` で小さなフォントもファイル化し、CSPのために `data:` の許可を追加しません。[Viteの資産埋め込み設定](https://vite.dev/config/build-options.html#build-assetsinlinelimit)を参照しています。HTML全体に `no-referrer` を指定し、参考リンクにも参照元を送らない設定を維持します。

## 将来Gatewayの応答

- 正規形のHTTPS固定URLのみ。認証情報・クエリ・ハッシュ・制御文字・バックスラッシュ・パーセント符号化・ドット区間・CSPの区切り文字を含む設定は拒否します。Gatewayのパス区間は英数字・ハイフン・アンダースコアに限定します。
- Cookieを送らず、参照元も送らず、リダイレクトは拒否し、応答をHTTPキャッシュへ保存しません。
- 本文取得を含めて3秒で終了します。JSONのContent-Typeを要求し、Content-Lengthの確認に加え、展開後のストリームの合計を32KiB以内に制限します。超過時・期限切れには読み込みをキャンセルします。
- 補足説明は4,000文字以内、関連IDの数・長さにも上限を設けます。不明なID・重複・想定外の応答項目・不可視制御文字を拒否し、静的説明に戻ります。接続能力の応答も未知の項目を拒否します。リダイレクト済み・opaque応答・別URLの応答を採用しません。
- 接続確認は同時要求を統合し、成功・失敗・手動確認のいずれでも5秒以内の再通信を抑えます。成功の通常キャッシュは60秒です。これをサーバー側のレート制限や認証の代わりにはしません。
- 解説の要求IDを検証直後に複製し、接続待ち中の引数変更で未検証のIDを送信しないようにします。
- 解説要求には許可済みIDだけを含めます。横断検索の契約案では固定の契約版・目的、最大20件の登録済み種類・IDだけを受け取ります。検索語・原文・任意プロンプト・任意URLを送る引数はありません。
- 横断検索の応答は1〜6件の候補に制限し、重複・候補外のID・未知の項目・URL・自由な文章を拒否します。接続状態に加え、検索機能の宣言を確認します。失敗時はローカル候補へ戻します。検索プロバイダは実画面に接続せず、モックだけで検証しています。

学内の実APIには接続していません。上の検証はすべてモックです。実際の認証・認可・レート制限・大学側の運用は、Gateway仕様が確定した後に別途設計・検証する必要があります。
