# 学生向けの環境・検索・ログ案内

更新日：2026-10-12。大学固有の設定と学生の実利用は未確認です。公開資料に基づく案内を実装しました。

## 保存からPDF作成まで

利用環境とエンジンを別々に選び、保存→実行→PDF確認を案内します。LinuxではEmacs標準TeXモード・AUCTeX・不明を選び、モード確認と既定の操作を確認できます。Windowsでは拡張子とエディタのビルド設定を確認します。OSからエンジンを推測せず、授業指定のテンプレートを優先します。文書クラスは既存のjlreqです。

保存名は `report-lualatex.tex` または `report-uplatex.tex` です。案内のコマンド・PDF・ログ名を保存名に揃えました。コマンド、PDFが作れない場合の手順、授業の設定、出典、Overleaf設定は必要時に展開します。

コマンドは列挙値として検証したエンジンと固定名だけから生成します。質問・アップロードファイル名・ソースを混ぜません。`-no-shell-escape` は外部コマンド呼び出しを無効にする例で、TeXのファイルアクセスや任意の文書の安全性を保証しません。アプリからTeX・シェルを実行する機能は追加していません。

## 目的・症状の言い換え

26トピックに70表現を追加し、「探す」と「まとめて調べる」で共有します。

| 入力例 | 案内する内容 |
| --- | --- |
| イコールをそろえたい | alignedの解説とレシピ |
| 分子と分母を書きたい | 分数の解説とレシピ |
| 画像が変な場所に出る | figureの配置とキャプション |
| 表の列数が合わない | tabularの列と区切り |
| 番号がはてなになる | label/refと再コンパイル |

開発時に作成した候補で、学生の質問や提出物を収集したものではありません。固定表現との照合です。検索のAND条件・タグ・種類・入力上限を維持し、未知の用語から回答を作りません。`purpose_phrases.json` はビルド時に参照・重複・制御文字・長さ・未知の項目を検証します。

## 追加のログ案内

既存7分類に、次の5分類を追加しました。原因や自動修正を断定しません。

| 報告 | 確認手順 |
| --- | --- |
| TeXコマンドが見つからない | OS側の起動失敗として、TeX環境・エディタの実行先を確認 |
| Extra / Misplaced alignment tab | 表の列数・&・行末を確認。2列の固定例をコピー可能 |
| There's no line here to end | 改行位置を確認。本文の段落の固定例をコピー可能 |
| Overfull hbox / vbox | 警告として表示。PDFのはみ出しを確認 |
| Emergency stop / Fatal error | 先行する最初のエラーを確認して再実行 |

起動失敗は既知のTeX関連コマンドと代表的なLinux・Windowsの形式に限定して読みます。一般文の「not found」から報告を作りません。Overfullの範囲は先頭行を表示し、原因位置とは限らないことを示します。従来の文字・容量・件数上限を維持します。

## 出典と読み込み

共通37資料に、操作・追加ログ用の6資料を `support_references.json` で追加しました（計43件）。種類・確認日・参照範囲と、安全な外部リンクを説明から確認できます。全文・画像・テンプレートは取り込みません。

操作は[GNU Emacs Manual](https://www.gnu.org/software/emacs/manual/html_mono/emacs.html)の保存・モード確認・TeX実行、[AUCTeX Manual](https://www.gnu.org/software/auctex/manual/auctex/Starting-a-Command.html)の文書処理を照合しました。オプションは[Web2c Manual](https://tug.org/texinfohtml/web2c.html)の該当説明を参照しています。直接取得が制限されたGNU・TUGのページは、取得できた検索索引の本文の該当範囲で確認しました。インストール済みバージョンの検証ではありません。

表の区切りは[The TeX FAQ：Alignment tab](https://texfaq.org/FAQ-altabcr)、改行は[No line here to end](https://texfaq.org/FAQ-noline)、はみ出しは[Overfull lines](https://texfaq.org/FAQ-overfull)を参照しています。The TeX FAQは保守者による資料として表示し、LaTeX本体の公式仕様と同一視しません。

言い換えは検索結果・専用画面で、追加資料はスターター・ログ案内の画面で読み込みます。基本ページの初期資産、CSP、入力の非送信・非保存を維持します。Emacsのモード選択も画面のメモリだけで、ページ離脱・再読み込みで消えます。

大学固有の設定・指定テンプレート、教員の校閲、実TeXコンパイル、学生試用は今後の確認事項です。
