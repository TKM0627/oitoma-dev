# 配布版と発表動画の範囲

方針確定：2026-10-12。作成者が最終発表に参加できず、一般観覧者も体験する前提です。

## 観覧者へ配布するアプリ

GitHub Pages対応の静的SPAとして配布します。LLMへの接続、学内アカウント、APIキー、VPN、作成者のPC、中継サーバー、トンネルを基本機能の利用条件にしません。

| 機能 | 配布版 |
| --- | --- |
| 書き方・レシピ・テーマ・エラー・コースの横断検索 | 利用可能 |
| 選択式の数式生成・KaTeX表示・コピー | 利用可能 |
| ソースの簡易診断・タイポ候補・ログ報告の確認 | 利用可能 |
| 質問・TeX・ログの「まとめて調べる」 | 登録済みの説明・固定例とローカル解析で利用可能。LLMの自由回答ではない |
| 日本語スターターの生成・保存、環境別の案内 | 利用可能 |
| テーマ別資料、記号一覧、学習コース・印刷 | 利用可能 |
| LLMによる自由回答 | 配布版に含めない |

`VITE_ENABLE_LIVE_AI=false`、Gateway設定は空欄のままです。公開用workflowでも無効に固定し、本番CSPはAPI通信を許可しません。入力・ファイル・質問を外部へ送信しません。完全なTeXコンパイル・PDF生成等、もともと未実装の機能を含むという意味ではありません。

公開操作はまだ実施していません。設定済みの配信環境へ実際に公開した後は、基本機能のために発表会場でNode.jsやPCサーバーを維持する必要はありません。

## 発表動画で紹介するLLM試作

LLMは開発中の通常アプリの「まとめて調べる」から使い、一般観覧者へ配布するビルドでは無効にします。専用の録画モードは設けません。発表動画への収録はこの開発中の画面を使います。外部公開やトンネルは不要です。

通常の開発画面に自動アクセス確認・質問と添付の送信・回答のコピー・横断案内を実装しました。2026-10-12、自作の短い質問で学内LLMの実APIの回答とLaTeXコードを取得しました。動画収録・動画ファイルは未実施です。紹介文は次の段階を区別します。

| 実際の確認 | 発表で使える表現 |
| --- | --- |
| 現時点の実装 | 「開発中のアプリに学内LLM接続を実装し、自作の質問で実APIの回答とLaTeXコードの取得を確認した。配布版では無効にする」 |
| 学内APIで実際に回答を取得できた後 | 「学内LLMとの実接続をローカル環境で確認した。配布版では無効にし、動画で試作を紹介する」 |
| 動画未収録 | 「LLM連携デモ動画がある」「組み込み済みで利用できる」とは表示しない |

動画では架空の短い質問と自作コード例だけを使用します。APIキー・認証画面・ヘッダー・Cookie・学内限定資料・個人情報・実アクセス統計を映しません。固定例やモックはその旨を明示し、本物のLLMの回答として見せません。

実接続には、大学の利用条件・仕様・入力の扱いを確認し、端末の `.env.local` にAPIキーとモデルIDを指定します。LLM接続は配布ビルドから除外し、loopback以外の開発サーバー起動・別サイトからのAPI操作を拒否します。[起動と情報の扱い](./LLM_CONNECTION.md)を参照してください。既存の限定ID向けGatewayとは別の通信処理です。

## 基本機能の動画・観覧者向け体験例

1. 「イコールをそろえたい」で検索し、複数行の数式レシピを開いてコピーする。
2. 「まとめて調べる」で「分数を大きくしたい」と入力し、登録済みコード例を確認する。
3. ソースに `\frca{a}{b}` を入力し、断定しないタイポ候補と位置を確認する。
4. 「直す」で数式内の空行を診断し、対応する開始位置と修正例を確認する。
5. ヘッダーで利用環境を切り替え、日本語スターターの保存手順とテーマ別資料を見る。

公開後に会場で配る基本機能のURLには、APIキーや入力内容を含めません。公開前の手順と検証結果は [README](../README.md)、LLMの条件は [確認一覧](./LLM_INTEGRATION_CHECKLIST.md) に記録しています。

UI簡素化後の確認：lint・build、単体/UIテスト549件、開発中のLLM画面のPC/スマホE2E6件、配布版E2E66件成功。自作の質問で実APIの回答とLaTeXコードを取得しました。厳密なWi-Fi限定の仕様・動画収録・サイト公開は未確認／未実施です。
